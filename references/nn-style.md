# 神经网络示意图风格规范

本文件只讲"神经网络/深度学习"类示意图:前向传播、反向传播、梯度流动、层结构。目标是一眼能讲清"信号往哪走、梯度往哪回"的教学图,不是论文里的密恐针线图。

## 版式骨架(两栏对照最清楚)

一张图同时表达前向与反向,最稳的是**左右两栏同一拓扑**:

```text
标题 + 副标题(图例:蓝实线=前向,橙虚线=反向)
┌──────────────────────────┬──────────────────────────┐
│ ① 前向传播 forward       │ ② 反向传播 backward      │
│ x -> a1 -> a2 -> yhat    │ d3 -> d2 -> d1 -> dx     │
│ 每列上方:层名 + 该层公式  │ 每列上方:该层 δ 公式     │
│ 最右:loss 框             │ 最右:loss 框             │
└──────────────────────────┴──────────────────────────┘
底部通栏:链式法则 4 条等式(前向/误差项/梯度/更新)
```

- 两栏节点用**同一 y 坐标**,方便读者横向对照同一层。
- 每栏独立图例太占地方,图例只放一次在右上角。

## 画布与配色

- 画布:`2800~3000 x 1700~1850`(两栏);单栏教学图 `1400~1600 x 1100` 即可。纸色/墨色/填充/线宽只在 `canvas.STYLE` 改,前向/反向色放图脚本开头。
- 前向 / 预测:`(31,111,205)` 蓝,实线,箭头向右。
- 反向 / 梯度:`(198,80,38)` 橙,虚线 `dash=(9,6)`,箭头向左。
- 节点填充:输入 `(240,243,248)` 灰、隐藏层 `(233,240,253)` 淡蓝、输出层 `(226,244,233)` 淡绿、loss 框 `(253,236,230)` 淡橙红;边线统一 `INK` 3px。
- 全连接边很多(4 层 3-4-4-2 共 36 条/栏):线宽取 2~3,颜色别太深;箭头 `head≈13`。

## 节点与连线的几何

- 节点:圆 `r=24`,层内间距 90,层间列距 340~360;一列节点用 `layer_ys(n, cy, pitch)` 算 y。
- 连线用公共助手,别手算端点(端点 = 圆心 ± 单位向量 × (r+1.5),贴圆外缘不插进圆):

```python
edge_arrow(sch, src, dst, color, dash=None)   # 节点 -> 节点
node_to_point(sch, node, p, color)            # 节点 -> loss 框/任意点
point_to_node(sch, p, node, color)            # loss 框/任意点 -> 节点
```

节点半径 `R` 若改动,调用时传同一个 `r=R`(默认 24)。

- 线段先登记、节点圆后登记(登记顺序就是绘制顺序;canvas 不会自动重排,必须先线后圆),线头会被圆盖住,接头干净。
- 前向箭头一律 `filled=True`;反向虚线箭头 `filled=True, dash=(9,6)`。
- 有 off-page 的"梯度回传"时可只画部分边并把线调淡,但**方向必须一致**。

## 文字层级与公式书写

- 标题 `title_block(sch, 60, 64, "标题", "副标题", size=40)`;栏头 28 Bold;层名 22 Bold;公式 17~18;图例/边注 18~20(次要注释可 16)。
- **公式用 `c.formula()` / `c.rich_line()` 排,不要再写 `^(...)` 文本上标**:

  ```python
  c.formula(540, 300, r"$z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}$", FORMULA, 17, anchor="mm")
  c.rich_line(60, 420, (("t", "反向:"),
                        ("f", r"$\delta^{(l)}=(W^{(l+1)})^\top\delta^{(l+1)}\odot\sigma'(z^{(l)})$")),
              FORMULA, 17)
  ```

  mathtext 会出真上下标、真分式、斜体变量与 ∂/⊙/⊤/←。约定:变量斜体、多字母函数名正体
  (`\mathrm{softmax}`)、代码变量 d 用 `\mathrm{d}`;矩阵乘用并置,不写 `@`。
- 公式里**不放中文**(mathtext 没有 CJK 字面),中文留在 `rich_line` 的 "t" 段。
- mathtext **不支持 `\begin{aligned}` 多行对齐**——多行就一行一条 `formula`,用同一 x 与
  `valign="baseline"` 对齐。17~18px 行内分式写 `(p-y)/n` 斜杠式,展示式(≥24px)用 `\dfrac`。
- `ŷ` 在纯文本里直接写(`Canvas.label` 自动组字),在公式里写 `\hat{y}`。
- **禁用豆腐块字符**(实测 Noto Sans CJK 缺字):`ᵀ ⊤ ⟵ ⟶ ˡ ⁻ ⁱ ₀₁₂`——纯文本里别用,公式里
  用 `^\top` / `\leftarrow` 代替;可放心用:`σ δ ∂ ⊙ η θ ← → · ≈ ∇ ⊗ ¹²³` 与全部汉字。
- 每层公式最多两行,行距 32~34;列距不够就把公式拆成两行而不是缩小字号(小于 16 就糊)。
- 必须给读者四个信息:前向链、loss、误差项递推、参数梯度/更新;缺一项图就"没说清"。

## 常见图种与要点

| 图种 | 要点 |
| --- | --- |
| 前向 + 反向双栏 | 拓扑同 y 对齐;δ 公式标在对应列;底部链式法则带 |
| 单层反向传播(微缩) | 只画 `∂L/∂W = δ a^T` 与 `δ` 回传箭头,放大公式 |
| 训练循环流程图 | 前向→loss→反向→更新 四阶段闭环,箭头方向/颜色区分 |
| 网络结构图(无传播) | 只画层与连接,用节点数/尺寸表达通道数,标注输出形状 |

## 自检

```sh
python3 scripts/nn_forward_backward.py   # 出 PNG 到 assets/
python3 scripts/verify.py nn             # 穿节点/标签重叠/文字出界
python3 scripts/verify.py 你的图.py       # 自己照范例写的新图
```

自检清单:

- [ ] 中文与公式无豆腐块、无截断
- [ ] 标签之间不重叠(verify.py 会报)
- [ ] 箭头端点贴节点外缘,不插进圆内
- [ ] 前向箭头向右、反向箭头向左,颜色/线型互斥
- [ ] loss 框、图例、公式带都完整落在画布内
- [ ] 两栏同层节点 y 对齐
- [ ] 图上能读出:前向公式、loss、δ 递推、参数梯度、更新式
