# 电路原理图风格规范

本文件只讲"电路类"图:门级原理图、逻辑框图、数字电路接线图。目标是**白底、线框感、可直接进讲义/网页的矢量风位图**,不做照片级/写实/风景效果。

## 画布与分辨率

- `Canvas(w, h)` 的 `w/h` 是**最终分辨率像素**;内部 `SS=2` 超采样后 LANCZOS 缩小,线宽/字号都按最终像素给。
- 典型尺寸:8 位 CLA 全图 `1950x3120`(竖版,每 bit 一行);小电路 `1200~1600` 宽足够。别小于 900 宽,中文会糊。
- 底色/墨色/门体填充/线宽是全局风格,只在 `canvas.STYLE` 改(别名 `BG/INK/FILL/WIRE_W` 可直接 import);各网络的语义色放在图脚本开头,别混进布局代码。

## 配色(照 CLA 范例)

| 用途 | 常量 | 值 |
| --- | --- | --- |
| 门体填充 | `FILL` | `(233,240,253)` 极淡蓝 |
| 门体/线框边 | `INK` | `(26,34,50)` |
| 传播 P 线 | `NET_P` | `(12,92,196)` 蓝 |
| 产生 G 线 | `NET_G` | `(198,40,40)` 红 |
| 进位 C 线 | `NET_C` | `(0,128,78)` 绿 |
| 和 S 线 | `NET_S` | `(108,40,158)` 紫 |
| 原始输入 | `NET_IN` | `(70,70,70)` 深灰 |
| 中间乘积项 | `TERM_C` | `(150,150,150)` 中性灰 |
| 注释箭头/说明 | 暖橙 | `(176,98,20)` |

规则:**同一个网络的每一段线必须同色**(读图靠颜色追踪信号);不同网络必须不同色;颜色总数 ≤ 7,超出就改分组或分层。

## 线宽与栅格

- 线宽 `WIRE_W=3`(最终 px);门体边同宽;图例色条可以 4。
- 布局像素级常量(CLA 范例):行距 `Q=340`、列距 `P=150`、小门 `80x52`、三角阵列门 `80x58`、行内 P 总线偏移 `-74`、行间通道上边界 `+86`、轨道间距 `LANE_PITCH=13`、轨道内边距 `LANE_PAD=14`。
- 自己定栅格时:

```text
行中心 y_i = Y0 + i*Q          # 每个 bit/单元一行
列中心 x_k = X1 + k*P          # 阵列第 k 列
```

- 所有门/器件对齐到行中心/列中心,不要用零散坐标,否则布线必然歪。

## 门符号(canvas 已提供,别重画)

| 符号 | 函数 | 说明 |
| --- | --- | --- |
| 与门 | `d_and(cx,cy,w,h)` | D 形:左边平直输入侧,右边半圆输出侧 |
| 或门 | `or_poly(cx,cy,w,h)` | 三段贝塞尔:上边/下边/向右凹的背弧 |
| 异或门 | `or_poly(...)` + `xor_arc(cx,cy,w,h,dx)` | 多一道左移的背弧;少了它和或门分不清 |
| 扇入宽或门 | `or_width(n)=56+18n` | 多输入引脚沿顶弧 `pin_on_top(t=(k+1)/(n+1))` 均匀分布 |
| 门符号图例 | `gate_legend(sch, x, y, (("与门","and"),("或门","or"),("异或门","xor")), title=...)` | 一次画出三种门 + 名字,间距/尺寸与正文门统一 |

引脚取点:或门类用 `pin_on_back/pin_on_top/pin_on_bot`(参数 t 是弧线参数,不要手算坐标);与门直接取左边中点/上下偏 11px。

## 布线原则(CLA 范例的硬经验)

1. **正交折线**:导线只走水平/垂直,斜线只留给注释箭头;折点直角。
2. **行间通道 + 轨道分配**:两个相邻单元之间的水平走线全部塞进通道,用 `assign_lanes(spans)` 做区间图贪心染色,重叠段分到不同 lane。不分配 = 不同网络共线 = 视觉短接。
3. **同网络扇出**:一个输出要喂多个输入时,画一条竖直干线 + 各分支,交点画 `junction()` 实心圆点;没有圆点 = 不相连,交叉线才不会误读。
4. **绘制顺序**:`canvas.py` 只按登记顺序画线/形(结点、文字最后),它**不会**自动把门体延后。所以要:先登记全部 `wire`,最后统一登记 `gate`/`stroke`(常见做法是门体先进队列,`build()` 末尾再登记)。这样不透明填充才能压住线头、盖住几像素擦边。
5. **引脚与端点**:每个输入/输出端点必须真正接到门体边上的引脚或另一个线段端点;断线是原理图最严重的错误,用 `verify.py` 查。
6. **图例色条**不是电路线,登记 `terminal()` 避免被自检误判断线。

## 文字与版式

- 标题用 `title_block(sch, 40, 46, "标题", size=36)`:左上角,自带可选副标题;下面放 3~5 行公式/说明(`size=20~21`,深灰 `(55,55,55)`)。
- 引脚名:`A0`、`B3`、`S7` 用 `anchor="rm"` 左对齐在输入侧;输出标签 `anchor="mm"`。
- 行内网络名(`P0`、`G0`、`C1`)字号 18~21,放在总线附近但要错开相邻行(行距 340 时,文字最多占 30px 高)。
- 公式里用中文"与/或/异或"或标准符号都行,同一张图统一;异或门符号必须画双背弧。
- 说明文字放图左上/右上留白区,不要压线;长说明按 30px 行距换行。

## 新增一张电路图的套路

1. 抄 `scripts/circuit_cla.py` 的骨架:`build()` 里先画标题/公式/图例/说明(`title_block`),再逐行建门并记录端口 dict,最后统一布线;收尾用 `save_asset`。
2. **先算几何**:把每个门的输入/输出引脚坐标记进 `rows`/`tri` 之类的 dict,不要边画边猜坐标。
3. **再登记连线**:先总线(水平/垂直主干),再分支,最后通道内用 `assign_lanes`;此时**只登记 wire**。
4. **最后登记门体**:把门多边形/异或门背弧攒进队列,所有导线登记完再统一 `sch.gate()/sch.stroke()`,否则导线会盖在门框上。
5. 跑 `python3 scripts/verify.py 你的图.py --logic` 直到 0 问题(需有 `build() -> Canvas`);再 `read_image` 目检。
6. 常见坑:线头伸进填充图形内部、通道里两条线共线、文字撞车、C0/进位标签压到相邻行。

## 自检清单

- [ ] 每个输入端都连着驱动端,输出端都引出
- [ ] 不同网络没有共线重叠(verify.py 的"不同网络共线重叠")
- [ ] 没有线穿门体(verify.py 的"线穿门体")
- [ ] 扇出交点有实心结点
- [ ] 门符号可辨认(与/或/异或)
- [ ] 文字不重叠、不出界(verify.py 的"文字重叠/出界")
- [ ] 逻辑与图一致(电路图可用 `logic_check` 仿真验证)

配套命令:

```sh
python3 scripts/circuit_cla.py               # 出 PNG 到 assets/
python3 scripts/verify.py 你的图.py --logic   # 几何 + 逻辑自检,0 才合格
```
